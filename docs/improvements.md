# Beadify Turbo 改进说明

Beadify Turbo 基于 [Jett-Wu/Perler_Beads_Generator](https://github.com/Jett-Wu/Perler_Beads_Generator)，起点固定为 [`36ac52d570246ab600611a79edd2236bccb954e5`](https://github.com/Jett-Wu/Perler_Beads_Generator/commit/36ac52d570246ab600611a79edd2236bccb954e5)。[ItsLucas/beadify-turbo](https://github.com/ItsLucas/beadify-turbo) 保留 Git 提交历史及上游 MIT [LICENSE](../LICENSE)。以下描述 0.5.1 的实际实现；原项目已有的画笔、填充、图层、3D 预览和 MARD 色卡继续复用，不列为本 fork 的原创功能。

| 范围 | 上游固定版本 | Beadify 的变化 |
|---|---|---|
| 生成与编辑保护 | 生成结果直接更新活动层，异步任务缺少统一项目版本保护 | Worker 执行新核心，支持取消和进度；任务 ID/项目 revision 拒收过期结果；先预览候选，接受后新增图层并隐藏旧层，一次撤销恢复 |
| CPU 制图核心 | 浏览器图片转换与画布耦合 | 共享 TypeScript RGBA 核心，浏览器 Worker 与 CLI 使用同一实现；支持面积、最近邻、主导色、结构优化及多网格位置比较；保留原版算法为默认和对照 |
| 主体与背景 | 以颜色距离去背景 | 裁切、边界连通去背景、保留/删除画笔；单独裁切外围白边，支持容差和撤销；保留原图比例 |
| 结构与细节 | 采样后清理碎点 | 使用源像素、跨色细线、部件形状和关键颜色证据；多初态搜索；提供高级权重和候选比较，目标是在有限格数和色数下保留结构 |
| 局部重算 | 缺少当前约束式重算流程 | 选区外格子锁定、颜色/空格锁、保护细节、简化与特征色约束；有原图缓存时可从原图重算，也可整理当前图纸；冲突显式报错 |
| 色数设置 | 已有基础 221 色、完整 291 色；界面和原转换 API 有限制 | 输入或一键使用全部 221/291 色；新核心执行硬色数上限；小部件保色与总色数约束共同检查。色卡本身来自上游 |
| 保存与兼容 | 旧版仅 cells 项目迁移可能丢图；无色卡/原图配置快照 | 修复旧图恢复，严格验证尺寸、色号和 schema；保存色卡快照、主体设置、源结构缓存、约束及文字分析；按原图内容 hash 关联；存储不足时分层降级并提示导出 |
| 导出与用量 | 隐藏层、重叠层的用量与可见图纸口径不统一 | PNG/SVG/PDF、CSV/JSON BOM、Excel 和侧栏按最终可见图纸计数；新增 SVG、分页 PDF、A4/Letter、页间重叠、镜像、毫米间距与校准尺 |
| 文字处理 | 无当前文字分析流程 | 手工区域/笔画标注、分析 JSON 导入导出、原字形增强候选、按原区域重新排字及背景修复；这些 CPU 功能也保留在轻量版 |
| 部署 | 单一工作台构建 | 提供统一的源码/静态部署、独立轻量包、systemd/Nginx 模板及校验清单 |
| 回归与对照 | 上游无 test 脚本 | Node 与 Chromium 检查；冻结的合成基准与失败记录；独立参考算法、盲评页面、Worker/CLI 等价验证 |

## 部署方式

支持[静态部署](lite-deployment.md)：可以从源码构建，也可以直接下载 [0.5.1 部署包](https://github.com/ItsLucas/beadify-turbo/releases/tag/v0.5.1)。开发环境与发行包使用同一套网页，提供 Node、Nginx 和 systemd 的运行说明。


## 当前边界

默认仍保留原版算法。结构优化适合与普通候选比较，小格数下的弯曲细线、斜线、眼内留白和复杂文字仍可能失真；制作前请核对图纸和实体颜色。

MARD 色卡沿用上游近似参考值，不代表品牌认证。来源与使用说明见 [第三方通知](../THIRD_PARTY_NOTICES) 和 [素材说明](../USAGE_RIGHTS.md)。
